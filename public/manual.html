📦4. ดูสต็อกสินค้า

เมนู สินค้าคงคลัง (หน้าแรก)

หาสินค้า

  1. พิมพ์ชื่อ / รหัส / บาร์โค้ด ในช่อง ค้นหา ตารางจะกรองทันที
  2. เลือกตัวกรองเพิ่มได้: หมวดหมู่ / สถานะ / ที่เก็บ / รอซ่อม
  3. กดหัวคอลัมน์ (เช่น คงเหลือ) เพื่อเรียงน้อย → มาก หรือ มาก → น้อย

อ่านสถานะ

ปกติ มีของพอ   ใกล้หมด เหลือไม่เกินจุดสั่งซื้อ   หมด เหลือ 0

ทางลัด: กดกล่องตัวเลขด้านบน (สินค้าทั้งหมด / ใกล้หมด / หมด) เพื่อดูเฉพาะกลุ่มนั้น กดอีกครั้งเพื่อยกเลิก

สรุปสินค้าใกล้หมด (การ์ด + บันทึกเป็นรูป)

  1. หน้า สินค้าคงคลัง → ปุ่ม ⚠ สรุปใกล้หมด
  2. ดูการ์ดสินค้าที่คงเหลือไม่เกินจุดสั่งซื้อ (รูป รหัส และจำนวนคงเหลือ เร่งด่วนที่สุดอยู่บนสุด) เลือกหมวดหมู่ได้ · ติ๊ก รวมสินค้าที่หมดแล้ว ถ้าอยากเห็นสินค้าที่เหลือ 0 ด้วย
  3. กด 💾 บันทึกเป็นรูปภาพ ได้ไฟล์ PNG ส่งต่อใน LINE ได้เลย หรือกด ส่งออก Excel
ดูรูปใหญ่: กดที่รูปสินค้าในตาราง  ·  ข้อมูลไม่อัปเดต? กด รีเฟรช

📥5. รับเข้าสินค้า

รับทีละรายการ

  1. เมนู รับเข้า / เบิกออก
  2. ช่อง สินค้า: พิมพ์ชื่อหรือรหัสสั้น ๆ เช่น AP → รายการขึ้นใต้ช่อง → คลิกเลือก (หรือกด Enter เลือกรายการแรก)
  3. ประเภท: เลือก รับเข้า
  4. ใส่ จำนวน · วันที่ (ค่าเริ่มต้นคือวันนี้) · หมายเหตุ (ถ้ามี)
  5. ดูช่อง ผลลัพธ์ ว่าคงเหลือหลังบันทึกถูกต้อง แล้วกด บันทึกรายการ

รับหลายรายการพร้อมกัน

  1. หน้า รับเข้า / เบิกออก หรือหน้า สินค้าคงคลัง → ปุ่ม ＋ รับเข้าหลายรายการ
  2. ใส่จำนวนรับเข้าที่สินค้าแต่ละตัว (ตัวที่ไม่ได้รับ เว้นว่างไว้)
  3. กดบันทึกทีเดียว
ทางลัด: ในตารางสินค้าคงคลัง กดปุ่ม + รับเข้า ท้ายแถว จะเปิดหน้ารับเข้าพร้อมเลือกสินค้าให้แล้ว

📤6. เบิกออกสินค้า

เบิกทีละรายการ

เหมือนรับเข้าทุกอย่าง แต่เลือกประเภท เบิกออก (เบิกเกินคงเหลือไม่ได้ ระบบจะเตือนสีแดง)

เบิกหลายรายการ (เช่น ใบสั่งขายส่ง)

  1. หน้า รับเข้า / เบิกออก → ปุ่ม － เบิกออกหลายรายการ
  2. พิมพ์ค้นหา → คลิกสินค้าทีละตัว สินค้าจะลงตาราง (Enter = เลือกรายการแรก)
  3. ใส่ จำนวนที่เบิกออก ของแต่ละแถว
  4. หมายเหตุ: พิมพ์เอง (เช่น ชื่อร้าน) หรือกดลูกศรเลือก ขายส่ง · ไม่ใส่ก็ได้ · ช่อง "ตั้งหมายเหตุทุกรายการ" ใส่ทีเดียวทุกแถว
  5. กด ยืนยันการเบิกออก
ปลอดภัย: บันทึกทั้งใบพร้อมกัน ถ้ามีแถวไหนผิด (เช่น ของไม่พอ) จะไม่บันทึกเลยสักแถว แก้แถวสีแดงแล้วกดยืนยันใหม่

🧾7. เบิกออกจาก PDF (ออเดอร์ออนไลน์)

สำหรับ Admin และ Store/QC · ใช้ใบหยิบสินค้าจาก Shopee / Lazada / TikTok

ขั้นที่ 1: เอาไฟล์ PDF จากเว็บ seller ให้ถูกวิธี

  1. เปิดใบหยิบสินค้า (Picklist / Checklist / Picking List) ในเว็บ seller
  2. กดปุ่ม ดาวน์โหลด (↓) หรือ Ctrl+P แล้วเลือกปลายทาง "บันทึกเป็น PDF"
ห้ามเลือก "Microsoft Print to PDF" เพราะจะได้ไฟล์ที่เป็นรูปภาพ ระบบอ่านไม่ได้ (จะขึ้นข้อความ "ไฟล์นี้เป็นรูปภาพ")

ขั้นที่ 2: เบิกในระบบ

  1. หน้า รับเข้า / เบิกออก → ปุ่ม － เบิกออกจาก PDF
  2. กด เลือกไฟล์ PDF เลือกได้หลายไฟล์พร้อมกัน (กด Ctrl ค้างแล้วคลิก)
  3. ตรวจตาราง (ดูความหมายสีด้านล่าง) แก้จำนวน หรือกด ✕ เอาแถวออกได้
  4. กด ยืนยันการเบิกออก · หมายเหตุจะเป็น "ออนไลน์" ให้เอง

ความหมายของสีในหน้าต่าง

🟩 กล่อง / แถวสีเขียว + ป้าย "ชุด"สินค้าที่มาจากชุดสุดคุ้ม (-P1) ระบบแตกเป็นชิ้นส่วนให้แล้ว เช่น เตา + หัวปรับ + สายแก๊ส
🟨 กล่องสีเหลือง = เบิกไม่ได้รหัสใน PDF ไม่ตรงกับระบบ หรือชุดยังไม่ได้ตั้งค่า → แจ้ง Admin ให้แก้รหัส แล้วเลือกไฟล์ใหม่
⏭️ "ข้าม … รายการ"คำสั่งซื้อนี้เคยเบิกไปแล้ว ระบบไม่ตัดซ้ำให้ (อัปโหลดไฟล์เดิมซ้ำได้ ไม่ต้องกลัว)
⚠️ "บางคำสั่งซื้อเคยเบิกแล้ว"เกิดกับ Shopee ที่รวมหลายออเดอร์ในแถวเดียว → ตรวจและแก้จำนวนเองก่อนกดยืนยัน

🔧8. ส่งซ่อม / ซ่อมเสร็จ / ปรับยอด / ตัดจำหน่าย

อยู่ในหน้า รับเข้า / เบิกออก เลือกจาก ประเภท

ประเภทใช้เมื่อผลต่อสต็อก
ส่งซ่อมของเสีย ต้องซ่อมคงเหลือ − / รอซ่อม +
ซ่อมเสร็จซ่อมแล้วกลับมาขายได้รอซ่อม − / คงเหลือ +
ตัดจำหน่าย (Admin, Store/QC)ซ่อมไม่ได้ ทิ้งรอซ่อม −
ปรับยอด (Admin, Store/QC)นับของจริงแล้วไม่ตรงระบบ+ หรือ − ตามที่ใส่ ต้องใส่หมายเหตุ
ส่งซ่อม / ซ่อมเสร็จ / ตัดจำหน่าย ต้องใส่เหตุผลในหมายเหตุ เช่น "สปาร์คเสีย"

📜9. ประวัติ และส่งออก Excel

เมนู ประวัติการเคลื่อนไหว · ดูได้ว่าใคร ทำอะไร เมื่อไร

  1. เลือกช่วงวันที่ หรือกดปุ่มลัด วันนี้ เดือนนี้ เดือนที่แล้ว
  2. กรองสินค้า / ประเภท / ช่วงเช้า-บ่าย ได้
  3. กด ส่งออก Excel ได้ไฟล์ตามตัวกรองที่เลือก

สรุปการเบิก เช้า-บ่าย

แท็บ สรุปการเบิก รวมยอดเบิกออกต่อสินค้า แยก เช้า (ก่อน 12:00) / บ่าย (12:00 เป็นต้นไป) · ติ๊ก แยกตามผู้บันทึก เพื่อดูว่าใครเบิกเท่าไร · ส่งออก Excel ได้

บันทึกผิด? ระบบไม่ให้ลบประวัติ ให้บันทึกรายการกลับ เช่น เบิกเกินมา 2 → รับเข้า 2 พร้อมหมายเหตุ "แก้ไขรายการ…" (หรือให้ Admin ปรับยอด)

📊10. ยอดขายรายเดือน

เมนู ยอดขายรายเดือน ดูยอดขายแต่ละเดือนของสินค้าแต่ละตัว และยอดขายเฉลี่ยต่อเดือน (ใช้ช่วยตัดสินใจสั่งของ)

✏️11. จัดการสินค้า (Admin, Store/QC)

+ เพิ่มสินค้าใหม่กรอกรหัส ชื่อ หมวดหมู่ หน่วย จุดสั่งซื้อ แล้วเพิ่มรูปได้
✎ แก้ไขกดปุ่มแก้ไขท้ายแถว แก้แล้วบันทึก
ปิดใช้งานสินค้าเลิกขาย ติ๊กเลือก → แถบล่าง "ปิดใช้งาน" (ข้อมูลเก่ายังอยู่ เปิดกลับได้ที่แท็บ "ปิดใช้งาน")
ตั้งหมวดหมู่หลายตัวติ๊กเลือกหลายสินค้า → แถบล่างเลือกหมวดหมู่
ตั้งจุดสั่งซื้อค่าที่ทำให้ขึ้น "ใกล้หมด" ตั้งเองหรือให้ระบบคำนวณจากยอดขายเฉลี่ย
นำเข้าไฟล์สต็อก / อัปเดตรูปใช้กับไฟล์ Excel สต็อกของร้าน (ใช้ไม่บ่อย)

🎁12. ชุดสินค้า (Bundle)

หน้า จัดการสินค้า → ปุ่ม ชุดสินค้า (Bundle)

ใช้บอกระบบว่า รหัสชุดสุดคุ้ม บนเว็บ seller (ลงท้าย -P1) ประกอบด้วยอะไร ตอนเบิกจาก PDF ระบบจะตัดชิ้นส่วนให้เอง

ตัวอย่างรหัสชุดระบบตัดสต็อก (ต่อ 1 ชุด)
GL-203R-P1 (เตา GL)เตา + VLP-889A + LGT001-P1
KB8A-VAB-P1 (เตา KB)เตา + VHP-103A + LGT001-P1 + VHB-001
WX-106-P1 (SK / WX / ZL / GH)เตา + VLP-889A + LGT001-P1
VLP-889A-P1 (หัวปรับ)VLP-889A + LGT001-P1
  1. กด + เพิ่มชุดใหม่ → ใส่รหัสชุดให้ ตรงกับในเว็บ seller
  2. ค้นหาแล้วคลิกสินค้าที่อยู่ในชุดทีละตัว ใส่จำนวนต่อ 1 ชุด
  3. กด บันทึกชุด
ชุดที่แพ็กไว้แล้วเป็นกล่อง (มีสต็อกเป็นสินค้า เช่น KB5A02-VAB-P1) ระบบจะตัดกล่องนั้นตรง ๆ จนหมด แล้วค่อยแตกเป็นชิ้นส่วน

💾13. สำรองข้อมูล (Admin, Store/QC)

  1. หน้า จัดการสินค้า → ปุ่ม ⭳ สำรองข้อมูล
  2. ได้ไฟล์ Excel (สินค้า / ประวัติ / ยอดขาย) เก็บไว้ในคอมหรือไดรฟ์
ควรทำอย่างน้อยสัปดาห์ละครั้ง ระบบจะเตือนเมื่อไม่ได้สำรองเกิน 7 วัน

❓14. ปัญหาที่พบบ่อย

เด้งออกให้เข้าสู่ระบบใหม่

ปกติ ระบบให้เข้าใหม่ทุก 12 ชั่วโมง เข้าสู่ระบบใหม่ได้เลย ข้อมูลไม่หาย

ไม่เห็นปุ่ม รับเข้า / เบิกออก

บัญชี Manager / Marketing / บัญชี ดูได้อย่างเดียว ถ้าต้องบันทึก ติดต่อ Admin

เบิกไม่ได้ ขึ้น "คงเหลือไม่พอ"

ของในระบบน้อยกว่าที่จะเบิก ตรวจของจริง ถ้าระบบผิดให้ Admin / Store/QC ปรับยอด ก่อน

PDF ขึ้น "ไฟล์นี้เป็นรูปภาพ"

ไฟล์ถูกบันทึกด้วย "Microsoft Print to PDF" ให้ดาวน์โหลดใหม่จากเว็บ seller หรือเลือก "บันทึกเป็น PDF" (ดูหัวข้อ 7)

PDF มีรายการในกล่องสีเหลือง

รหัสใน PDF ไม่ตรงกับระบบ หรือเป็นชุด -P1 ที่ยังไม่ได้ตั้ง แจ้ง Admin ให้แก้รหัสหรือเพิ่มชุด (หัวข้อ 12) แล้วเลือกไฟล์ใหม่ รายการอื่นเบิกไปก่อนได้

บันทึกผิด อยากลบ

ลบไม่ได้ (เพื่อให้ตรวจย้อนหลังได้) ให้บันทึกรายการกลับ หรือให้ Admin ปรับยอด พร้อมหมายเหตุ
